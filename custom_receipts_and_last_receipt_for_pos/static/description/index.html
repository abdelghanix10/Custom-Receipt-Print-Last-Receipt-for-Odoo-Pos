Can I apply different receipt designs to different POS locations?

Yes, absolutely! Each POS location can have its own custom receipt design. When setting up each POS, you can choose a specific receipt design for that location, allowing you to maintain consistent branding across different stores or customize for specific needs.

How does the "Print Last Receipt" feature work?

The Print Last Receipt feature automatically detects the most recent paid order in your current POS session. Simply click the "Print Last Receipt" button and the system will instantly reprint the last transaction receipt. This is perfect when customers request a duplicate receipt or for record keeping.

Is it possible to edit receipt designs without affecting POS operations?

Yes, you can edit receipt designs in the backend without interrupting POS operations. Changes are applied only after the design is saved and the POS is refreshed, allowing seamless updates and customizations without disrupting your sales workflow.

Can I preview the receipt design before applying it?

You can test the design by selecting it in the backend and processing a test transaction or using the print last receipt feature to see how the design looks in practice. We recommend testing new designs in a non-production environment first.

Does this module work with thermal printers?

Yes! This module is fully compatible with thermal printers and all standard POS receipt printers supported by Odoo. The custom receipt designs are optimized for various printer types and paper sizes.

What happens if there's no last receipt to print?

The module includes smart error handling. If there's no previous paid order in the current session, the system will display a clear notification message informing you that no receipt is available to print. This prevents confusion and ensures a smooth user experience.
